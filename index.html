Experimentos Multiplayer

Este repositório reúne experimentos de jogos multiplayer, cada um mantido em sua própria pasta dentro de /playground/<name>/. Esta página lista todos os experimentos disponíveis para você abrir diretamente, sem precisar decorar o caminho de cada um.

Para rodar um jogo localmente: cd playground/<name> && npm install && npm start.
